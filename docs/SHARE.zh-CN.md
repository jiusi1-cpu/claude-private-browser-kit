## 详细介绍

### 不想为了 Claude，改掉整台电脑的默认浏览器

这个项目从一个很具体的问题出发：Claude Desktop 打开的网页，能不能进入它自己的浏览器，而其他软件继续使用原来的浏览器？

仅新建一个浏览器资料目录不够。桌面端的外部链接和 Playwright MCP 的浏览器启动是两条不同路径，配置好其中一条，并不意味着另一条自动改变。

Claude 专用浏览器工具包整理了这几部分：

- 只在 Claude 进程内适配外部网页打开，不替换系统默认入口。
- 独立 Edge 程序与资料目录，配合按程序路径生效的网络限制。
- 不联网的只读静态检查器，区分通过、失败和尚未验证。
- 代理中断、UDP、DNS 等真实行为的检查清单，以及脱敏历史记录。
- 说明改了什么、如何核对、如何恢复的回滚参考。

用户无需逐条手动执行教程，可以把这些材料交给有本机操作能力的 Agent；只有聊天能力的 AI 无法替你配置电脑。当前仍有明确缺口：没有完成全新机器部署验收，登录后的真实 Claude 模型驱动 MCP 全链路也未被现有证据证明。

这不是代理销售项目，也不是防封工具。独立资料目录不等于完整安全沙箱。欢迎带版本号、复现步骤和脱敏结果来反馈，让这套方法逐步变得更可复现。
