# Claude 防封方案：实测与边界 / Evidence Update

## 发布定位 / Release scope

中文展示名为 **Claude 防封方案**，英文展示名为 **Claude Account Risk Toolkit**。
保留原仓库地址，避免既有链接失效。名称不是对防封效果的承诺。
Windows 实测有效仅指下面列明的工程检查，不是封号率实验。

This is a Windows environment-audit and browser-separation reference, not a proven
ban-prevention product. Public source does not include a vendor binary, logged-in
profile, proxy subscription or a ready-to-use copy of the author's installation.

## 公开研究怎么用 / Interpreting public reports

- [GitHub #51583](https://github.com/anthropics/claude-code/issues/51583)：付费用户自述企业 VPN 使用后账号受限。VPN 是报告者推测，非确认的封禁原因。First-person report, not a causal finding.
- [GitHub #44244](https://github.com/anthropics/claude-code/issues/44244)：旧版 Windows Cowork 代理继承及 UDP/IPv6 问题报告。用于设计独立验收，不据此断言本机复现。Older-version networking report, not proof of a current defect.
- [GitHub #31476](https://github.com/anthropics/claude-code/issues/31476)：Windows Google OAuth 回调循环报告。登录回调故障不能直接归为风控。Authentication routing errors are not equivalent to suspension.
- [X 个人经历](https://x.com/oyacaro/status/1927627973697700230)：只能作个案线索，没有可靠样本分母或服务端原因证据。Anecdote, not a ban-rate estimate.
- [X 环境组合推广](https://x.com/AI_Jasonyu/status/2035687356104102330)：检索内容包含付费合作与推广链接；住宅 IP、指纹浏览器和老邮箱的效果不能由推广自述证明。Commercial claims are not controlled evidence.
- [claude-sonar](https://github.com/AschoofAlpha/claude-sonar)：环境一致性检查的参考项目，未安装、未作为依赖，也未对其安全性作全面审计。Reference only, not a vetted dependency.

X 检索仅覆盖可公开访问或索引的内容，部分原帖访问受限。所有链接都是外部资料，
不是安装指令或自动执行授权。没有足够证据计算个人封号概率，也没有证明清理
Cookie、购买老邮箱或更换指纹能解除服务端限制。

## 下一步 / Next steps

1. 保留当前会话，先做本地只读核验。Preserve sessions; inspect first.
2. 在空闲窗口单独验收 Code/Cowork/MCP 和真实流量。Test each workload separately.
3. 评估签名有效、可更新的客户端方案，再做有备份的迁移。Prefer maintainable signed clients.
4. 服务使用资格、账号申诉和数据备份不能由代理设置代替。Network settings do not establish eligibility.
